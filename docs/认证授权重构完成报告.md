## 架构变化

### 重构前
```
请求 → JwtAuthenticationFilter → AuthenticationInterceptor → @RequireIdentity 切面 → Controller
         ↓                              ↓                           ↓
    SecurityContextHolder          检查临时Token限制            检查身份类型权限
    AppSessionContext (主要使用)
```

### 重构后
```
请求 → JwtAuthenticationFilter → Spring Security FilterChain → Controller
         ↓
    SecurityContextHolder (存储 UserPrincipal)
         ↓
    @PreAuthorize 注解 (方法级权限控制)
```

## 使用方式

### 1. 在 Controller/Service 中获取用户信息

```java
// 方式1：通过 SecurityUtils 获取
@GetMapping("/profile")
public Result<UserProfile> getProfile() {
    Long userId = SecurityUtils.getCurrentUserId();
    Long merchantId = SecurityUtils.getCurrentMerchantId();
    Long customerId = SecurityUtils.getCurrentCustomerId();
    IdentityType identityType = SecurityUtils.getCurrentIdentityType();
    // ...
}

// 方式2：通过方法参数注入
@GetMapping("/profile")
public Result<UserProfile> getProfile(
    @AuthenticationPrincipal UserPrincipal currentUser
) {
    Long userId = currentUser.getUserId();
    Long merchantId = currentUser.getMerchantId();
    // ...
}
```

### 2. 使用权限注解

```java
// 类级别权限控制
@RestController
@RequestMapping("/api/merchant")
@PreAuthorize("@authz.isMerchantOwner()")
public class MerchantController {
    // 所有方法都需要商户身份
}

// 方法级别权限控制
@PreAuthorize("@authz.isCustomer()")
@GetMapping("/customer/orders")
public Result<List<Order>> getCustomerOrders() {
    // 只有客户身份可以访问
}

// 检查是否已选择身份
@PreAuthorize("@authz.hasSelectedIdentity()")
@GetMapping("/some-endpoint")
public Result<Data> someEndpoint() {
    // 需要已选择身份（商户或客户）
}
```
