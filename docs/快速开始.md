# Core Ledger 代码改进和监控 - 快速开始

## 🎯 概述

已完成针对 **2核4G** 服务器的代码改进和监控部署方案。

## ✅ 已完成的工作

### 1. 代码改进 (5项)

- ✅ **Spring Boot Actuator + Prometheus**: 应用指标暴露
- ✅ **Logback 日志配置**: 结构化日志，滚动策略
- ✅ **API 请求日志 (AOP)**: 自动记录所有 API 请求
- ✅ **Redis 缓存**: 商户信息缓存，减少数据库压力
- ✅ **自定义业务指标**: 账单、支付、客户等业务指标

### 2. 监控系统 (3个组件)

- ✅ **Prometheus**: 指标收集和存储
- ✅ **Node Exporter**: 系统指标采集
- ✅ **Grafana**: 可视化平台

## 🚀 快速部署

### 步骤 1: 重新编译应用

```bash
cd /mnt/h/core-ledger/core-ledger-service
mvn clean package -DskipTests
```

### 步骤 2: 重启应用

```bash
# 重启应用 (根据你的部署方式)
java -jar target/core-ledger-service-1.0.0-SNAPSHOT.jar
```

### 步骤 3: 验证 Actuator

```bash
# 健康检查
curl http://localhost:8080/code-ledger/actuator/health

# Prometheus 指标
curl http://localhost:8080/code-ledger/actuator/prometheus | head -20
```

### 步骤 4: 启动监控

```bash
cd /mnt/h/core-ledger/monitoring
docker-compose up -d
```

### 步骤 5: 访问界面

- **Grafana**: http://localhost:3000 (admin/admin123)
- **Prometheus**: http://localhost:9090

### 步骤 6: 导入仪表板

在 Grafana 中导入以下 Dashboard ID:
- **10280**: Spring Boot Statistics
- **4701**: JVM Metrics
- **1860**: Node Exporter

## 📈 监控指标示例

### 应用性能

```promql
# QPS (每秒请求数)
rate(http_server_requests_seconds_count{application="core-ledger-service"}[1m])

# P95 响应时间
histogram_quantile(0.95, rate(http_server_requests_seconds_bucket[5m]))

# 错误率
rate(http_server_requests_seconds_count{status=~"5.."}[5m])
```

### 业务指标

```promql
# 账单创建速率
rate(business_ledger_created_total[5m])

# 支付成功率
rate(business_payment_success_total[5m]) / (rate(business_payment_success_total[5m]) + rate(business_payment_failure_total[5m]))
```

### 系统资源

```promql
# CPU 使用率
100 - (avg(irate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)

# 内存使用率
(1 - (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes)) * 100
```

## 🚨 告警规则

已配置的告警 (在 Prometheus 中查看: http://localhost:9090/alerts):

1. **ApplicationDown**: 应用宕机 > 1分钟
2. **HighCPUUsage**: CPU > 80% 持续 5分钟
3. **HighMemoryUsage**: 内存 > 85% 持续 5分钟
4. **HighDiskUsage**: 磁盘 > 85% 持续 5分钟
5. **HighErrorRate**: 5xx 错误率 > 5% 持续 5分钟
6. **SlowAPIResponse**: P95 响应时间 > 1秒 持续 5分钟
7. **HighJVMMemoryUsage**: JVM 堆内存 > 85% 持续 5分钟
